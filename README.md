# RocketCollector_sfml-ecs-game
A 2D rocket-collecting game built with C++17 and SFML 3.1, powered by a hand-written ECS architecture.

自己搓了个简易的ECS框架，用这个框架做了个用鼠标控制火箭吃金币的小游戏，大概耗时5天，纯手搓。

## 操作方式 | Controls

| 操作 | 功能 |
|---|---|
| 移动鼠标 / Move Mouse | 控制火箭移动 / Control the rocket |
| Enter | 切换全屏 / Toggle fullscreen |
| Escape | 退出游戏 / Exit game |
